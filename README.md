# Mobile App Wireframing

## App Idea
This project is a To-Do List mobile application designed to help users manage daily tasks easily.

## User Research
- Users want a simple way to track tasks
- Users need quick task entry
- Users prefer minimal design
- Users want to mark tasks as completed

## Persona
Name: Rahul  
Age: 20  
Occupation: Student  
Goal: Manage daily tasks efficiently  

## User Flow
Home → Add Task → Save → Back to Home
